# Architecture

- `index.html` is the whole app: CSS, a catalog (`const CAT`), article text (`RES`), and JS. No build step.
- `sw.js` is the service worker: offline cache (name = `VERSION`), plus push and notification-click handlers.
- `manifest.webmanifest` holds install info and the app-icon shortcuts (`?go=...` deep links).
- `worker/worker.js` is the Cloudflare Worker for push notifications (see worker/README.md). `releases.json` feeds it.
- `tools/` holds generators; `tests/` holds Playwright browser tests.

## Inside index.html
Early script: `APP_VERSION` and a small error capture (`window.__errs`) used by "Report a problem".
Main script: state `S`, `save()`/`render()`, views per tab. Helpers: `el(tag,cls,text)`, `btn(txt,fn,cls)`, `$`.
Later sections are marked `/* ---------- ... ---------- */` and mostly live in IIFEs that extend `window.LT` (the tools object): hubs, Safety and consent, Hold pad, The Count, Trigger Mix, Notifications, care and safety.
Dialogs use `cxOpen(title, build)`, `cxClose()`, `cxDismiss()` with a back-stack. The hubs (`HUBS`) list tools; `GO`, `GUIDES` and `TOOLS` register deep links and help text.

## Gotchas
- Functions at top level are global; things inside an IIFE are not. A feature that reads another IIFE's variable must go through `LT` (this caused the "Every texture" achievement bug). Lint's `no-undef` helps.
- Themes: `:root[data-album=X]` variables plus `html[data-skin=X]` rules. The v59 themes are generated by `tools/gen-themes.py` between marker comments. Do not hand-edit that block.
- Safety UI (Emergency Exit, Quick hide, Get help) must work with no network and must never write tracking data.
